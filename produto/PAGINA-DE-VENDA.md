## Pare de repetir as mesmas regras para o Claude Code toda vez

O Claude Code começa cada sessão sem lembrar do seu projeto. Sem regras escritas, você explica tudo de
novo, recebe código fora do seu padrão e não sabe por que o resultado muda tanto de um dia para o outro.

O **Kit Claude Code** reúne o que eu uso para resolver isso: modelos de `CLAUDE.md` prontos, prompts
testados e checklists curtos.

### O que vem no kit

- **5 modelos de `CLAUDE.md`** para: site/front-end, API/back-end, script em Python, projeto de dados
  e IA, e um mínimo para qualquer projeto. Copie, troque os `[colchetes]` e pronto.
- **20 prompts prontos**, organizados por etapa: planejar, implementar, revisar, depurar, testar e
  refatorar, documentar e entregar. Cada um diz para que serve.
- **4 checklists:** começar um projeto, aceitar o código que o Claude escreveu, publicar, e o que
  fazer quando ele erra sempre a mesma coisa.
- **Guia de comandos** conferido na documentação oficial: `/init`, `/plan`, `/compact`, `/clear`,
  `/rewind`, `Shift+Tab` e outros, com quando usar cada um.
- Tudo em arquivos de texto (Markdown). Abre em qualquer editor e no celular.

### Para quem é

- Quem está começando com Claude Code e quer um jeito organizado de pedir as coisas.
- Quem já usa e percebe que repete as mesmas instruções ou recebe código fora do padrão.

### Para quem não é

- Quem procura um curso em vídeo ou mentoria. É um kit de arquivos, não um curso.
- Quem espera que o Claude faça tudo sozinho sem revisão. Os prompts ajudam, mas você continua
  revisando o que ele escreve. O kit ensina a pedir a prova, não promete resultado.

### Como usar (15 minutos)

1. Rode `/init` no seu projeto.
2. Complete o `CLAUDE.md` com o modelo do seu tipo de projeto.
3. Use o prompt 1 (plano antes de editar) na sua próxima tarefa.

### Perguntas frequentes

**Funciona com qualquer linguagem?** Os modelos têm exemplos de JavaScript/TypeScript e Python. A
estrutura serve para qualquer linguagem, trocando os comandos.

**Preciso saber programar?** Ajuda. O kit assume que você já usa ou vai usar o Claude Code num
projeto de código.

**O Claude Code muda, o kit fica velho?** O Claude Code muda rápido. O kit só cita comandos que
estão na documentação oficial e traz a data da conferência. A versão 1 recebe atualizações.
