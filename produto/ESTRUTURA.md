# Produto: Kit Claude Code (R$ 17)

Documento de planejamento. O produto em si está em `kit-claude-code/` e o texto de venda em
`PAGINA-DE-VENDA.md`.

## 1. Problema e público

- **Quem compra:** quem está começando com Claude Code (estudante, dev júnior, autônomo, quem aprendeu
  a "programar com IA") e perde tempo repetindo regras, recebendo código fora do padrão e sem saber
  como pedir.
- **Dor real:** o Claude Code começa cada sessão sem memória; sem um `CLAUDE.md` bom e sem prompts
  claros, o resultado varia muito e o iniciante não sabe por quê.
- **Evidência de demanda:** o Reels do `CLAUDE.md` já recebeu comentário pedindo o material, e os
  perfis de referência vendem produto parecido (R$ 47 o "Super Claude", pacotes de prompts de US$ 5 a 29).

## 2. Requisitos (MoSCoW)

**Must**
- Modelos de `CLAUDE.md` para os tipos de projeto mais comuns, prontos para copiar.
- Biblioteca de prompts testáveis, organizada por etapa do trabalho.
- Checklists curtos (começar projeto, aceitar código).
- Guia de comandos com **só o que está na documentação oficial**.
- Tudo em arquivos de texto simples (Markdown) que abrem em qualquer lugar.

**Should**
- Versão em PDF para ler no celular.
- Página de venda honesta, sem promessa de resultado financeiro.

**Could**
- Vídeo curto de demonstração.
- Atualização do kit quando o Claude Code mudar.

**Won't (agora)**
- Curso em vídeo, comunidade, mentoria, suporte individual.
- Promessa de renda ou de "vibe coding sem saber nada".

## 4. Preço e funil

- **Grátis (já no ar):** `robo-estagiario.zip` com 1 modelo e 1 prompt de planejamento.
- **Pago:** este kit, **R$ 17** (decisão do Davi em 2026-10-18; antes pensado R$ 27), pagamento único. Preço de entrada por ser perfil novo; o concorrente
  mais próximo cobra R$ 47. Subir depois de ter prova social.
- **Ponte:** uma linha no `LEIA-ME` do grátis apontando para o kit completo.
- **Plataforma de pagamento:** a escolher pelo Davi (exige conta e CPF dele).

## 5. Qualidade do conteúdo (como saber se está bom)

- **Verificação (consistência):** todo comando ou atalho citado existe na documentação oficial
  (code.claude.com/docs). O que não foi confirmado fica de fora.
- **Validação (resolve a dor?):** antes de vender, 3 pessoas do nicho usam o kit num projeto real e
  dizem o que travou. Ajustar com base nisso.
- **Atributos que importam:** adequação funcional (funciona copiando e colando), usabilidade
  (curto, escaneável), manutenibilidade (fácil de atualizar quando o Claude Code mudar).

## 6. Riscos

- O Claude Code muda rápido. Mitigação: só comandos documentados e uma data de atualização no topo.
- Prompt não é garantia. Mitigação: o texto de venda não promete resultado, só método.
- Cópia do conteúdo. Mitigação: baixo preço e atualizações; conteúdo é de método, não segredo.
- Aviso legal: este kit não tem vínculo com a Anthropic.
